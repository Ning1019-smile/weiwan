1. 背景与目标

观察到的问题：大学生的待办事项来源分散——教务系统、课程群、老师口头布置、社团与生活事务。任务以"截止时间（DDL）"驱动，一旦漏记或遗忘，就会出现赶工、迟交、漏考等问题。现有通用待办工具对"课程、学期、考试"等校园概念支持薄弱，而多数在线工具要求账号登录、依赖网络。

产品响应：做一个单机、免登录、数据全部本地的任务管理 App，默认面向大学生的任务结构（作业、考试、课程表、学期）深度建模，同时允许关闭学生模式作为通用任务清单使用。

可观察的目标：

  • G1 录入快：从打开输入到保存一条带截止时间的任务，不超过 3 次点击 / 约 3 秒。
  • G2 打开即清晰：启动 App 或查看桌面卡片，无需任何操作即可看到"今天要做什么"与"最近一次考试 / DDL 倒计时"。
  • G3 不漏 DDL：任何设置了截止时间的任务，默认都会在截止前触发一次本地提醒。
  • G4 离线可用：飞行模式下全部核心功能可用，数据不丢失。

2. 产品定位与产品契约

项定义
首要用户大学生（本科 / 研究生），任务围绕课程、作业、考试与校园生活组织
次要用户关闭学生模式后的通用用户（职场人士等），使用普通的任务清单能力
触发时刻接到新任务（布置作业 / 约定事务）时记录；规划一天 / 一周时查看；担心遗漏 DDL 时核对
核心工作记录任务 → 按紧迫度组织 → 截止前提醒 → 完成并归档
完成标志任务被勾选完成并进入"已完成"归档；DDL 前用户收到过提醒；用户可在任意视图找到任何未完成任务
共享业务对象任务（Task），可绑定课程（Course），课程归属学期（Term）
信任原则无账号、无联网、无广告；数据只存本机；提供导出备份作为丢失恢复手段
学生模式定位深度集成：课程 / 学期 / 考试是一等对象，任务体系原生围绕它们组织；模式开关只隐藏入口、不删除数据（见 规则 R4）

3. 版本范围（P0 / P1 / P2）

3.1 最小完整旅程（P0）

  • 入口条件：安装后打开即用，无注册登录。
  • P0 动作：创建学期与课程（学生模式）→ 录入任务（可设类型、课程、DDL）→ 在今日聚焦 / 列表查看 → DDL 前收到本地提醒 → 勾选完成。
  • 完成证据："今天"页面展示逾期 / 今日任务与最近考试倒计时；完成后任务进入"已完成"分区。
  • 关键恢复路径：删除任务需二次确认；已逾期任务可一键"改期到今天"。

3.2 版本划分

优先级内容对应需求
P0 任务增删改查与完成、今日聚焦、列表视图、DDL 紧迫度排序、学生模式开关、学期与课程管理、作业 / 考试类型与倒计时、本地通知提醒、本地存储 FR-01 ~ FR-07、FR-11 ~ FR-19、FR-25
P1 日历 / 四象限 / 看板视图、课程表周视图（含单双周）、重复任务、桌面服务卡片、备份导出导入、最近删除（30 天可恢复） FR-08 ~ FR-10、FR-15、FR-20 ~ FR-21、FR-26 ~ FR-27
P2 完成统计与热力图、连续打卡、番茄钟、深色模式 FR-22 ~ FR-24、FR-28

3.3 明确排除（本期不做）

  • 云同步、多设备同步、账号体系；
  • 任务协作、分享、社交功能；
  • 商业化（广告 / 内购）；
  • iOS / Android 跨端版本。

4. 对象模型与任务状态

4.1 任务（Task）

字段必填说明与取值
标题必填≤ 50 字，纯文本
类型必填普通 / 作业 / 考试 / 事务，默认"普通"。作业与考试为学生模式语义类型
课程选填学生模式开启时可选；绑定后可在课程详情聚合查看
截止时间选填精度为"日期"或"日期 + 时间"；仅日期时视为当天 23:59（见 规则 R3）
优先级选填无 / 低 / 中 / 高，默认"无"
备注选填纯文本长备注
提醒选填默认继承全局提前量（见 规则 R5），可按任务覆盖
重复选填P1：每天 / 每周 / 自定义间隔；完成后自动生成下一期
状态系统待办 / 已完成 / 已逾期（派生状态，见 4.4）
创建 / 完成时间系统自动记录，用于排序与统计

4.2 课程（Course）

字段必填说明与取值
课程名必填如"高等数学"
教师选填文本
地点选填文本
上课时间选填周几 + 节次，可多条；单双周设置为 P1（[假设] 单双周属 P1）
所属学期必填关联当前学期

4.3 学期（Term）

字段必填说明与取值
学期名必填如"2026 秋季学期"
起止日期必填开始日期 < 结束日期；同一时间有且仅有一个"当前学期"

历史学期与课程数据保留，可查看其关联的任务归档；[假设] 不提供学期归档的编辑入口之外的特殊处理。

图 1 · 任务状态转换。"已逾期"为派生状态，由共享规则 R3 在每日 0 点 / 打开应用时结算，不是用户直接设置的状态。

5. 功能需求

5.1 M1 任务管理 P0

目的：让用户以最低成本记录、维护任务，是所有视图与提醒的数据基础。

ID能力用户与触发产品行为规则与状态
FR-01快速录入 任何用户；点击首页 / 列表页底部"＋"或首页快捷输入框 打开新建面板：标题默认聚焦；提供"今天 / 明天 / 本周末"快捷日期片；可展开设置类型、课程、截止时间、优先级、提醒、备注。保存后任务进入"待办"，并出现在对应视图 标题必填 ≤ 50 字，为空时保存按钮置灰并提示；仅填标题即可保存（DDL 等均可空）；保存后展示轻提示"已添加"
FR-02查看与编辑 任何用户；点击任意任务行 进入任务详情：展示全部字段与状态；点击字段直接进入编辑，保存即时生效 已完成任务亦可编辑备注 / 补充信息；编辑 DDL 会按新值重新计算提醒与紧迫度
FR-03完成与撤销 任何用户；点击任务行左侧勾选框 勾选 → 状态变"已完成"，记录完成时间，取消其未触发的提醒，任务移入"已完成"分区；再次点击勾选框可撤销回"待办" 完成 / 撤销即时生效并同步所有视图与桌面卡片；重复任务完成后按 P1 重复规则生成下一期
FR-04删除 任何用户；在列表左滑任务行或详情页点"删除" 弹出确认框（含任务标题），确认后删除 P0：确认即删除，提示"可在设置中开启删除前备份"（P1 生效）；P1：删除进入"最近删除"保留 30 天（FR-27）
FR-05逾期改期 任何用户；任务进入"已逾期"后在行内或详情页操作 提供"改期到今天 / 明天"快捷按钮，以及自选日期；改期后回到"待办"并重设提醒 已逾期任务在所有视图中置顶显示（排序见 R2）

目的：同一份任务数据提供多种组织视角；P0 只做"今日聚焦 + 列表"，其余视角 P1 迭代。

5.3 M3 学生模式 P0 P1

目的：把"学期 — 课程 — 作业 / 考试"建模为一等对象，让校园任务的录入与查找天然贴合学生场景；这是本产品与通用待办工具的核心差异。

ID能力用户与触发产品行为规则与状态
FR-11学期管理 学生用户；首次开启学生模式，或"我的 → 学期设置" 创建学期（名称 + 起止日期），可创建多个；当前日期落在起止区间内的学期为"当前学期"，无匹配时取结束日期最晚的未来学期 开启学生模式但无学期时，引导页要求先建一个学期才能继续；学期可编辑、删除（删除需确认，且仅允许删除非当前学期）
FR-12课程管理 学生用户；"课程"页 → 新建 / 编辑课程 维护课程（名称必填，教师 / 地点 / 上课时间选填），课程归属当前学期 删除课程需确认：其关联任务不删除，仅解除绑定（类型保留）；[假设] 不提供跨学期复制课程
FR-13任务绑定课程 学生用户；新建 / 编辑类型为"作业 / 考试"的任务时 可从当前学期课程中选择绑定；课程详情页聚合展示该课程全部任务（未完成在前） "普通 / 事务"类型不提供课程字段；学生模式关闭时字段隐藏、已绑定关系保留（R4）
FR-14考试倒计时 学生用户；存在类型为"考试"且截止日期在未来的任务时 首页顶部显示倒计时卡：取最近一场考试，显示"距《考试名》还有 N 天"；同日多场时显示全部并按课程名排列 N ≤ 7 时卡片转为强调色；考试日当天显示"今天开考"；[假设] 已过期的考试任务不再展示，进入已完成 / 逾期归档
FR-15课程表周视图 P1 学生用户；"课程"页切换"课表"模式 按周展示课程格（周几 × 节次）；点课程格查看课程任务；提供"给这门课布置作业"快捷入口（预填课程字段的 FR-01） 支持单双周标记；非当前周显示周次导航
FR-16学生模式开关 任何用户；"我的 → 学生模式" 开关切换即时生效：关闭后隐藏课程页签、倒计时卡、课程 / 学期入口与任务上的课程徽标；开启后全部恢复 统一行为见 R4；不删除、不改写任何数据

5.4 M4 提醒 P0

目的：在正确的时间把 DDL 推到用户面前（目标 G3），全部基于系统本地通知，不依赖网络。

ID能力用户与触发产品行为规则与状态
FR-17DDL 提醒 任何用户；任务设置了截止时间 按任务提醒设置（默认继承 R5）在截止前通过系统通知提醒；通知点击后直达该任务详情 仅日期（无时刻）的 DDL，提醒时刻为截止日前一天 20:00（R3）；[假设] 默认提前量取"截止前 1 天"
FR-18提醒生命周期 系统；任务完成 / 删除 / 改期 / 编辑时 完成与删除 → 取消全部未触发提醒；改期 / 编辑 DDL → 撤销旧提醒并按新值重设 提醒与任务状态严格一致，不允许出现"任务已完成仍收到提醒"
FR-19通知权限 任何用户；首次保存带提醒的任务时 请求系统通知权限；拒绝后不阻塞流程，任务详情显示"提醒未开启"角标，"我的"页常驻开启指引入口 权限被拒期间创建的提醒设置保留，授权后自动补注册

5.5 M5 桌面服务卡片 P1

目的：不打开 App 即可掌握今日任务与最近 DDL（目标 G2），是鸿蒙平台的差异化体验。

ID能力用户与触发产品行为规则与状态
FR-20卡片规格 任何用户；长按桌面图标添加卡片 2×2：今日任务数 + 最近一条 DDL；2×4：今日任务前 3 条 + 考试倒计时（学生模式开启时） 卡片内容与 App 内"今日聚焦"同源；点击卡片直达对应任务或今日页
FR-21卡片刷新 系统；任务数据变化或跨日时 任务增删改、完成 / 撤销后即时刷新卡片；每日 0 点按 R3 重新结算展示 无网络依赖；数据不变时不无谓刷新

6. 共享规则

R1 · 紧迫度分级

所有视图、卡片、排序共用同一套紧迫度定义（按未完成任务的 DDL 计算）：

级别定义展示色
已逾期当前时间已过 DDL 且未完成红
今天DDL 为今天橙
3 天内DDL 在明天 ~ 3 天内黄褐
本周内DDL 在 4 ~ 7 天内蓝
更晚 / 无日期DDL 在 7 天以外，或未设置 DDL灰

R2 · 排序规则

  • 分区顺序固定：已逾期 → 今天 → 未来 7 天 → 更晚 → 无日期；已完成始终置底折叠。
  • 分区内：DDL 升序 → 优先级降序（高 > 中 > 低 > 无）→ 创建时间升序。
  • 已逾期任务在"今日聚焦"置顶于今日任务之前。

R3 · 逾期结算

  • 结算时机：每日 0 点系统结算一次；应用从后台返回前台时补算一次。
  • 带时刻的 DDL 以该时刻判定；仅日期的 DDL 以当天 23:59 判定。
  • 结算只影响"未完成"任务；已完成任务不因时间流逝改变状态。

R4 · 学生模式开关的统一行为

  • 关闭 = 仅隐藏入口与展示：课程页签、学期 / 课程设置入口、考试倒计时卡、任务行上的课程徽标、新建面板的课程字段。
  • 任务数据、课程数据、学期数据全部保留；已绑定课程的任务在关闭模式下正常显示（只是不显示课程名）。
  • 开启 = 全部入口与展示恢复；不触发任何数据迁移。

R5 · 提醒默认值

  • 全局默认提前量：[假设] 截止前 1 天（仅日期 DDL 时为前一天 20:00），可在"我的"中修改（30 分钟 / 2 小时 / 1 天 / 2 天）。
  • 新任务默认继承全局值；单任务可覆盖，覆盖后与全局值解耦。
  • 修改全局默认值只影响之后新建的任务，不回溯已存在任务。

R6 · 空状态

每个视图定义空态引导：今日 / 列表为"添加第一件事"；课程为"创建第一门课"；统计为"完成第一个任务后这里会有数据"。空态均带一个主操作按钮。
